## Sobre el proyecto

**NEXUS** es una plataforma de inteligencia de proyectos impulsada por IA generativa (Google Gemini). Permite a equipos y usuarios individuales analizar, planificar y ejecutar proyectos con asistencia inteligente en tiempo real. La interfaz oscura y moderna combina visualizaciones de datos con un asistente conversacional, ofreciendo una experiencia de product management de próxima generación.

## Tecnologías utilizadas

| Tecnología | Versión | Rol |
|---|---|---|
| React | 19 | UI framework principal |
| TypeScript | 5.8 | Tipado estático |
| Tailwind CSS | 3.4 | Estilos y diseño |
| Vite | 6 | Bundler y dev server |
| Google Gemini AI | 2.4 | Motor de inteligencia artificial |
| Motion | 12 | Animaciones fluidas |
| Lucide React | 0.546 | Iconografía |

## Características

- **Dashboard inteligente** — Métricas de proyectos en tiempo real con análisis de riesgos y progreso
- **Asistente IA integrado** — Chat conversacional con Gemini para consultas sobre el proyecto
- **Gestión de tareas** — Kanban board con priorización automática y estimaciones de tiempo
- **Análisis de riesgos** — Identificación y evaluación de riesgos con sugerencias de mitigación
- **Reportes ejecutivos** — Generación automática de informes en lenguaje natural
- **UI/UX premium** — Diseño oscuro con gradientes, glassmorphism y animaciones fluidas

## Modelo de negocio

**B2C (Business to Consumer)**

NEXUS está orientado a usuarios individuales, freelancers y equipos pequeños que necesitan herramientas de gestión de proyectos potenciadas por IA sin la complejidad de soluciones enterprise. El modelo freemium permite acceso básico gratuito con funcionalidades avanzadas mediante suscripción.

## Ejecutar localmente

**Requisitos previos:** Node.js 20+

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/JuanTrezza/NEXUS-Project-Intelligence-Platform.git
   cd NEXUS-Project-Intelligence-Platform
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Configurar la API key de Gemini en `.env.local`:
   ```
   GEMINI_API_KEY=tu_api_key_aqui
   ```

4. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

5. Abrir [http://localhost:5173](http://localhost:5173) en el navegador.

## Build para producción

```bash
npm run build
```

Los archivos compilados se generan en `./dist` y son desplegados automáticamente en GitHub Pages al hacer push a `main`.

## 🧠 Sobre el Proyecto

**NEXUS** es una landing page SaaS de gestión de proyectos con inteligencia artificial. Una plataforma moderna y elegante diseñada para equipos que quieren **gestionar más rápido y liderar con inteligencia**.
